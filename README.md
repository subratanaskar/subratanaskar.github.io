# Subrata Naskar — Portfolio

Static site (HTML / CSS / JS, no build step) for GitHub Pages, live at **subro.me**.

```
index.html          page markup (all sections + My Story panel)
css/style.css       all styles — Season Sans, navy grid, colours from the Figma file
js/main.js          loader, Hello eyes, pixel portrait, taxi, side-scroll work, toolkit physics…
js/portrait.js      pixel-art data for the portrait
assets/video/       subro-face.mp4 (1s loader) + project videos
assets/img/         face, logos, project images
assets/fonts/       Season Sans TRIAL .woff2 files
```

## Editing
- **Projects** — titles, text and links live in `index.html` under *Selected Work*.
- **Social links / email** — footer and the Contact button's `mailto:` link.

## Publish
Served by GitHub Pages from `main`, on the custom domain in `CNAME` (subro.me).
Search engines are blocked for now (`robots.txt` + `noindex` meta). Remove both to allow indexing.
